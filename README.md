# Fullstack App (Learning Template)

## 🎯 Objective
Follow the instructions inside each file to build:
- Authentication system
- REST API
- Angular frontend

## 🧱 Backend Tasks
- Setup Flask app
- Connect to MySQL
- Create User model
- Implement auth routes

## 🟢 Frontend Tasks
- Build login & register forms
- Connect to backend API
- Handle responses

## 🚀 How to Run

### Backend
- Activate virtual environment
- Install requirements
- Run app.py

### Frontend
- Run `ng serve`

## 💡 Notes
- Do NOT copy solutions—follow instructions and implement yourself
